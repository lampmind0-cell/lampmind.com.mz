Política de Privacidade

Última atualização: 26 de julho de 2026

Esta Política de Privacidade explica como a LampMind ("nós") recolhe, usa e protege os dados pessoais de quem visita ou usa o site lampmind.tech ("o Site"). Ao usar o Site, aceitas as práticas aqui descritas.

1. Que dados recolhemos

Formulários que preenches: nome e email (formulário "Faça parte da LampMind"); nome, email, telefone, área de atuação, nível académico, área de estudo e motivação (questionário de candidatura à equipa); nome, tipo e mensagem (formulário de feedback/reclamações/sugestões).

Interação com o Site: registamos, de forma anónima, o número de visitas às páginas e os "gostos" (likes) dados — sem associar estes dados a uma identidade pessoal.

Armazenamento local do navegador: usamos o localStorage do teu navegador apenas para lembrar se já deste "like", evitando likes repetidos. Este dado fica só no teu aparelho.

2. Para que usamos os teus dados

  • Responder a mensagens, candidaturas e pedidos que nos envies;
  • Enviar novidades sobre projetos, cursos e conteúdos, apenas a quem se inscreveu voluntariamente;
  • Avaliar candidaturas para integrar a equipa LampMind;
  • Melhorar o Site com base em estatísticas gerais de utilização (visitas, likes, feedback);
  • Cumprir obrigações legais, quando aplicável.

3. Com quem partilhamos dados

Não vendemos nem alugamos os teus dados pessoais. Usamos os seguintes prestadores de serviço para operar o Site, que processam dados em nosso nome:

  • Supabase — armazenamento da base de dados e ficheiros do Site;
  • Resend — envio de emails de notificação a quem se inscreveu;
  • YouTube — apenas para apresentar vídeos e o link do nosso canal.

4. Quanto tempo guardamos os dados

Guardamos os dados de contacto e candidaturas enquanto forem relevantes para o propósito para o qual foram recolhidos, ou até nos pedires a sua remoção.

5. Os teus direitos

Podes, a qualquer momento, pedir para: aceder aos dados que temos sobre ti; corrigi-los; ou apagá-los. Basta contactar-nos através do email ou telefone indicados na secção de Contacto do Site.

6. Segurança

Os dados são protegidos através de regras de acesso (Row Level Security) na base de dados, que impedem o acesso público a informações sensíveis — só a equipa autorizada da LampMind consegue consultar candidaturas e mensagens de contacto.

7. Alterações a esta política

Esta política pode ser atualizada de tempos a tempos. A data no topo desta página indica a versão mais recente.

8. Contacto

Para qualquer questão sobre esta política ou sobre os teus dados, contacta-nos pelos meios indicados na secção de Contacto do Site.

Este documento é um modelo geral e não substitui aconselhamento jurídico. Recomendamos revisão por um profissional de direito para garantir conformidade total com a legislação aplicável em Moçambique.
